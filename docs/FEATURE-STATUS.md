# Feature status

Go-Lewah is **in active development and has not launched publicly yet**. "Implemented" means built in the
development environment (the Radio rows are also covered by the automated tests described in the documentation
samples). It does not mean in use by schools.

## Implemented (development environment)

| Area | Status |
|---|---|
| School set-up: classes, streams, subjects, book lists, administrators with distinct roles | Implemented |
| School and personal timetables | Implemented |
| Pupil and teacher attendance (day / week / month), absence notes | Implemented |
| Homework | Implemented |
| Exams and results with approve → publish workflow; Cameroonian report-card format | Implemented |
| Fees and billing: class fees, instalments, fee slips, payments, balances (FCFA) | Implemented |
| Canteen meals; extra and holiday classes; school events and celebrations | Implemented |
| Role-based portals (administrator, teacher, student, parent, vendor) with mobile layouts | Implemented |
| Messages and notifications in English and French | Implemented |
| Consent screens and per-child permissions managed by parents | Implemented |
| Used-books exchange and vendor marketplace | Implemented |
| Platform (HQ) administration, support and append-only audit trail | Implemented |
| **Radio — governance:** station switch, responsibilities accepted by the school's Super Admin, delegated duties, restrictions, suspensions, history | Implemented |
| **Radio — programmes:** requests and approval, Anchor / Studio Producer / co-hosts / reporters, ten standard templates, school templates, recurring programmes with per-episode changes, announcements | Implemented |
| **Radio — Live Studio:** one shared studio with server-enforced permissions, preparation screen, live broadcasting (up to 3 hosts and 1–12 approved speakers), reporter turns, timed pause / mute / revoke / remove, live school announcements, story suggestions, compact timetable | Implemented and tested with simulated microphones |
